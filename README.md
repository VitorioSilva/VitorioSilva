## Sobre

Desenvolvedor Back-End com foco em **Python** e ecossistema de APIs de alta performance. Trabalho com arquiteturas escaláveis, processamento assíncrono, otimização de queries e integração entre serviços.

Atuação direta em:
- Design e implementação de **APIs REST**
- **Tarefas assíncronas** e filas de processamento
- Modelagem de dados e **otimização de queries**
- **Autenticação/autorização** (JWT, OAuth2, RBAC)
- Integrações com gateways de pagamento, serviços externos e mensageria

Foco em código limpo, testável e preparado para produção — não em script que funciona só na máquina local.

## O que eu faço

- **APIs REST profissionais** com versionamento, documentação automática (OpenAPI/Swagger) e validação robusta
- **Autenticação completa**: JWT, refresh tokens, OAuth2, permissões granulares
- **Processamento assíncrono** com Celery para tarefas pesadas (envio de e-mail, geração de relatórios, integrações)
- **Cache e performance** com Redis (cache de consultas, rate limiting, sessões)
- **Modelagem de banco** pensando em integridade, índices e performance
- **Testes automatizados** garantindo contrato de API e regras de negócio
- **Deploy** com Docker, orquestração de containers e boas práticas de produção
